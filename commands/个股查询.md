# stock-check

按独门战法判断股票进场时机，识别二波机会和A字杀风险。

## ⚠️ 前置依赖

**本技能依赖 `a-share-data` 技能获取A股实时数据，使用前请先安装：**

```bash
# 克隆仓库
git clone https://github.com/shouldnotappearcalm/a-share-skill.git

# 安装到 Claude Code 全局技能目录
mkdir -p ~/.claude/skills
cp -R a-share-skill/a-share-data ~/.claude/skills/

# 重启 Claude Code 使技能生效
```

**仓库地址：** https://github.com/shouldnotappearcalm/a-share-skill

**a-share-data 提供的能力：**
- 实时行情、日/周/分钟K线
- 技术指标（MA/MACD/KDJ/RSI/BOLL等12种）
- 财务数据（盈利/成长/偿债/现金流）
- 市场情绪（热点板块、北向资金、龙虎榜、涨停板）
- 宏观数据（指数成分股、存款利率、货币供应量）

---

## 触发条件

用户提供股票代码或股票名称时自动触发。

## 核心功能

1. **基础信息搜索**：自动搜索近30天走势、财报、板块、题材
2. **二波机会判断**：识别洗盘/换庄/出货形态
3. **A字杀预警**：识别下跌破位信号，分级风险提示
4. **投资周期建议**：给出短中长线操作建议

### 第一步：使用 a-share-data 技能自动拉取数据

**⚠️ 重要：直接调用 `/a-share-data` 技能获取所有数据，无需用户截图**

使用 `Skill` 工具调用 `a-share-data`，获取以下数据：

1. **近30天日K线数据**
   - 调用：`/a-share-data` 获取近30个交易日的日K线
   - 包含：开盘价、收盘价、最高价、最低价、成交量、换手率
   - 重点看：有没有连板/翻倍/冲高回落

2. **技术指标**
   - MACD（DIF、DEA、柱状图）
   - MA均线（5日、10日、20日、60日）
   - 成交量变化趋势
   - 重点看：金叉/死叉、均线支撑/压力、量能递增/递减/一致

3. **实时行情与分时数据**
   - 当日分时走势（如果是交易时间）
   - 最新价格、涨跌幅
   - **⚠️ 重要：集合竞价价格仅用于判断当天强弱预期，不计入分时最高/最低价分析**

4. **财务与板块数据**
   - 所属板块/概念
   - 行业地位（通过市值、营收在板块中的排名判断：龙头/前三/中规中矩/杂毛）
   - 最新财报数据（净利润、营收增长率）

5. **市场情绪数据**
   - 是否上龙虎榜（最近5天）
   - 北向资金流向
   - 涨停/跌停情况

6. **🔴 业务线深度拆解与板块映射（必做！不能只看申万行业分类）**

**⚠️ 核心教训：申万行业分类（如"化工原料"）只是会计分类，不代表股票真正的驱动力。**
很多公司的估值和股价由高成长业务线驱动，而这些业务线可能属于完全不同的赛道。

**必须执行以下搜索：**
- 搜索：`{股票名称} 核心业务 产品线 营收构成`
- 搜索：`{股票名称} 下游应用 客户 产业链`
- 搜索：`{股票名称} 电子材料 半导体 新能源 新材料`

**输出格式（必须输出）：**
```
🏢 业务线拆解与板块映射：

业务线1：[产品名称] → 下游：[具体应用] → 受益板块：[板块A、板块B]
- 板块地位：[龙头/供应商/新进入者]
- 今天该板块涨跌：[+X.XX% / 数据缺失]

业务线2：[产品名称] → 下游：[具体应用] → 受益板块：[板块C]
- ...

⚠️ 估值驱动判断：
- 基本盘业务：[传统主业，稳定估值]
- 成长期权业务：[高成长赛道，估值弹性来源]
```

**关键原则：**
- 官方申万行业分类（如"基础化工"）是财务口径，不代表股价驱动力
- 一只股票可以同时属于多个赛道（如圣泉=化工+PCB+半导体封装+光刻胶）
- 板块表现对比时，**必须用实际业务映射的板块**，而不能只看申万行业
- 如果公司的成长性来自某个高估值赛道，该赛道今日表现才是判断"是否独立走强"的基准

**⚠️ 必须使用 `WebSearch` 深度搜索未来预期与题材催化（这是核心能力）：**

**A. 基础题材搜索：**
- 搜索关键词：`{股票代码/名称} 最新公告 利好消息 2026`
- 判断：有无政策催化、重大事件

**B. 深度催化挖掘（必做）：**
1. **参股公司IPO计划**
   - 搜索：`{股票代码/名称} 参股 投资 IPO 上市计划`
   - 搜索：`{股票代码/名称} 持股公司 子公司 上市`
   - 重点：找出所有参股/控股公司的IPO进展、估值预期

2. **重大项目与订单**
   - 搜索：`{股票代码/名称} 重大合同 订单 2026`
   - 搜索：`{股票代码/名称} 项目中标 业绩预期`

3. **政策与行业催化**
   - 搜索：`{股票代码/名称} 所属行业 政策利好 2026`
   - 搜索：`{板块名称} 行业趋势 政策扶持`

4. **业绩预期与重组**
   - 搜索：`{股票代码/名称} 业绩预告 扭亏为盈`
   - 搜索：`{股票代码/名称} 重组 并购 资产注入`

**输出格式：**
```
📊 未来预期与催化剂：
✅ 已确认：[具体事件 + 时间节点 + 潜在影响]
⚠️ 传闻/进行中：[具体事件 + 当前进展]
❌ 无明显催化
```

### 第三步：用户提供信息后，综合判断

#### 对照五大维度分析

**🔴 核心判断法则：量能不能替代筹码！**

| 组合 | 结论 |
|------|------|
| 筹码不动 + 量能一致/递减 | ✅ **洗盘锁仓**（主力控盘浮筹洗完，量自然稳） |
| 筹码上移 + 量能一致 | ⚠️ **换庄**（新老资金交替，量稳说明新庄控盘） |
| 筹码清零 + 量能递增 | ❌ **出货**（主力跑路，散户接盘） |

**⚠️ 没有筹码数据时，量能一致不能作为换庄依据。必须先让用户提供筹码峰截图再下结论。**

| 维度 | ✅ 洗盘（蓄力二波） | ⚠️ 换庄（有望二波） | ❌ 出货（无二波） |
|------|-------------------|-------------------|-----------------|
| **底部筹码** 🔴 | 基本不动，高度稳定 | 老筹码减少，中位形成新筹码峰 | 筹码全部分散至高位散户区 |
| **量能表现** | 全程缩量，低换手<br>量能递减 | 阶段性连续放量，后期逐步缩量<br>**连续几天量能一致 + 筹码上移** → 换庄<br>**暴量后缩量** → 换庄完成 | 持续放量下跌，量能永不衰减<br>**量能递增** → 出货加速 |
| **K线形态** | 小阴小阳，波动极小 | 高位宽幅震荡，长影线频发 | 阴包阳、连续大阴线、破位下跌 |
| **分时走势** | 走势平缓，波动有限 | 日内大起大落，反复震荡博弈 | 急拉慢跌、单边阴跌 |
| **价格位置** | 上涨中途，守住关键均线 | 高位平台震荡，不深跌、不破平台 | 逐步跌破平台、均线彻底破位 |

**⚠️ 筹码峰是五大维度中的锚定维度（🔴标记）。没有筹码数据时，量能/K线/分时/价格只能提供线索，不能替代筹码判断。**

## 判断规则详解

### 一、二波机会判断规则

#### ✅ 常规洗盘（蓄力二波）

**筹码特征：**
- 回调阶段底部低位筹码峰稳定
- 筹码流失比例 < 20%
- 高位无巨型密集套牢峰

**量能特征：**
- 回调全程缩量
- 成交量、换手率持续走低
- **量能递减** → 主力控盘，不出货
- **量能一致 + 筹码不动** → 洗盘锁仓（浮筹洗完，量自然稳，不是换庄！）

**K线特征：**
- 小阴小阳为主，波动平缓
- 10日/20日关键均线不有效跌破

**分时特征：**
- 走势平缓，波动有限

**结论：** 主力还在，洗盘蓄力，有二波机会

---

#### ⚠️ 换庄形态（有望二波）

**筹码特征：**
- 原有底部老筹码大批量减少、逐步上移
- 筹码未彻底分散给散户
- 在阶段中位区间形成全新密集筹码峰
- 完整换庄周期一般 3~5 个交易日
- ⚠️ 单日筹码剧烈变动 → 优先判定为出货

**量能特征：**
- 换庄区间阶段性持续放量
- 连续多日高换手（单日换手率普遍 20%+）
- 整体量能远高于第一波上涨均量
- 换庄初期：放量震荡，阴阳K线交替
- 换庄中后期：量能逐步温和回落、趋于平稳
- **连续几天量能一致 + 筹码上移** → 换庄（新庄控盘中）
- **暴量后缩量** → 换庄完成
- **⚠️ 必须同时满足筹码上移条件！筹码不动+量能一致=洗盘，不是换庄**

**K线特征：**
- 高位宽幅震荡
- 长上影、长下影K线频繁出现
- 日内涨跌幅度大（±5%为常态）
- 无连续跌停、无单边断头铡阴线
- 股价牢牢守住第一波高位平台
- ⚠️ 一旦平台失守 → 判定换庄失败

**分时特征：**
- 日内大起大落，反复震荡博弈

**龙虎榜判断：**
- 询问用户是否有龙虎榜数据
- 检查游资/机构进出情况
- 看是否有新资金大额承接

**结论：** 新庄接盘，有二波概率，但风险高于洗盘

---

#### ❌ 出货形态（无二波）

**筹码特征：**
- 底部筹码快速清零
- 筹码全部分散在高位区间
- 形成大面积散户套牢峰

**量能特征：**
- 持续放量单边下跌
- 量能永不衰减
- **量能递增** → 出货加速，恐慌盘涌出

**K线特征：**
- 阴包阳、连续大阴线、破位下跌
- 有效跌破关键均线

**分时特征：**
- 急拉慢跌、单边阴跌

**结论：** 主力已跑路，无二波、无换庄可能

---

### 二、下跌破位判断规则

#### ⚠️ 预警级（轻度破位）

**信号：**
- 单根放量阴线
- 跌破短期均线（5日/10日）
- 急拉慢跌分时

**操作建议：** 反弹减仓，设防守位，不加仓不抄底

---

#### 🚨 确认级（中度破位）

**信号：**
- 两日大跌超20%
- 阴包阳（单日巨量阴线覆盖前2~3根阳线）
- 高位套牢峰形成

**操作建议：** 反弹分批清仓，严格执行止损

---

#### 💀 极端级（重度破位/A字杀）

**信号：**
- 连续跌停
- 单边阴跌（老奶奶下楼梯）
- 流动性枯竭（缩量跌停/缩量大跌）

**操作建议：** 不博弈，有反弹立即离场

---

### 三、特殊形态识别

#### 🚫 地天板（诱多识别）

**前置条件：**
- 全天长时间封死跌停
- 封单由大转小、多次开板
- 当日换手20%~40%
- 标的为人气龙头

**核心规则：**
- ⚠️ 高位连板票尾盘地天板，90%为诱多出货
- 地天板不作为止跌、反转、换庄、二波的判断依据

---

### 四、投资周期建议

#### 短线适合条件（几天到几周）
- 股价刚突破关键压力位/放量拉升
- 有热点题材/政策催化/短期利好
- 技术面强势（MACD金叉、均线多头排列）
- 但基本面一般，炒的是预期和情绪

#### 中线适合条件（1-3个月）
- 股价在相对底部区域/刚启动不久
- 业绩有改善趋势但还没完全兑现
- 板块有中期逻辑支撑（产业周期、政策扶持）
- 估值合理或偏低

#### 长线适合条件（半年以上）
- 股价在历史大底/严重低估
- 基本面优秀且持续盈利增长
- 行业龙头地位稳固/护城河深
- 未来3-5年成长空间大

## 输出格式

### 最终给用户的结论必须包含：

1. **🏢 业务拆解与多维度板块映射（必须优先输出）**：
   - **传统业务**：申万行业分类 + 板块地位（基本盘估值锚）
   - **成长业务**：实际赛道/概念板块映射（股价真正的驱动力）
   - 每一条业务线 → 下游应用 → 受益板块 → 今日该板块涨跌
   - **估值驱动判断**：基本盘 vs 成长期权，哪个在主导当前股价？
   - ⚠️ 禁止只用申万一级行业（如"化工原料"）概括所有业务

2. **📊 未来预期与催化剂（必须优先输出）**：
   - ✅ 已确认催化：参股公司IPO、重大订单、政策利好等
   - ⚠️ 进行中/传闻：具体事件 + 当前进展
   - 时间节点与潜在影响（估值提升空间、业绩弹性）
   - ❌ 如无明显催化，明确说明

3. **形态判断**：洗盘/换庄/出货？

4. **二波机会**：有/无/概率多大？

5. **技术指标分析**：
   - 支撑位/压力位（关键价格区间）
   - MACD状态（金叉/死叉/背离）

## 重要原则

1. **商用合规**：不存储任何股票信息，每次都是全新问答
2. **引导式判断**：通过问答方式让用户自己判断，不直接给买卖建议
3. **数据驱动**：所有判断必须基于搜索到的数据 + 用户提供的截图
4. **风险优先**：发现破位信号时，优先提示风险
5. **客观中立**：不夸大机会，不隐瞒风险
6. **⚠️ 未来预期优先**：必须深度挖掘参股公司IPO、重大订单、政策催化等未来预期，这是判断股票价值的核心维度
7. **⚠️ 业务拆解决定分析质量**：不能只看申万行业分类，必须拆解公司实际产品线，映射到真正的赛道板块。**2026.05.28 圣泉集团教训：误把电子材料龙头当化工原料股，板块对比完全错误，用户当场纠正。**

## 注意事项

- **a-share-data 无法提供筹码峰数据**，如需精确判断底部筹码稳定性，需用户补充筹码分布图截图
- 龙虎榜数据可通过 a-share-data 获取，但用户截图更直观
- 分时走势通过 a-share-data 获取实时数据
- **集合竞价价格仅供参考，不计入分时最高/最低价分析**
- 所有判断都要对照五大维度表格，不能凭感觉
- 遇到地天板形态，直接按诱多处理，不给二波预期
- **量能一致性必须结合筹码判断**：筹码不动+量能一致=洗盘锁仓；筹码上移+量能一致=换庄。无筹码数据时不得单凭量能一致判换庄
- **⚠️ 禁止表面化板块分析**：申万行业分类（如"基础化工"）只是财务口径，不代表股价驱动力。必须拆解公司实际业务线，映射到真正的赛道板块（如PCB、半导体封装、光刻胶等），并用这些板块的今日表现做对比。**如果只用一个申万行业分类概括所有业务，分析作废。**
- **板块地位通过市值/营收在板块中的排名判断**
- **⚠️ 未来预期挖掘是必做项，不能遗漏**：
  - 必须搜索参股公司IPO计划（如"金风科技 蓝箭航天 IPO"）
  - 必须搜索重大订单与项目中标
  - 必须搜索政策催化与行业趋势
  - 这些信息直接影响股票估值和二波机会判断
