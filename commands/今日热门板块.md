# sector-leader-finder

自动挖掘热门板块龙头股，筛选上升趋势+未来预期好+资金面强势的个股。

## ⚠️ 前置依赖

**本技能依赖 `a-share-data` 技能获取A股实时数据，使用前请先安装：**

```bash
# 克隆仓库
git clone https://github.com/shouldnotappearcalm/a-share-skill.git

# 安装到 Claude Code 全局技能目录
mkdir -p ~/.claude/skills
cp -R a-share-skill/a-share-data ~/.claude/skills/

# 重启 Claude Code 使技能生效
```

**仓库地址：** https://github.com/shouldnotappearcalm/a-share-skill

---

## 触发条件

用户询问"今天什么板块强"、"最近热门板块"、"板块龙头推荐"等关键词时自动触发。

## 核心功能

1. **热门板块识别**：自动获取当天前3热门上升板块 + 近7天强势板块
2. **龙头股筛选**：从板块中筛选市值前3、成交额靠前的龙头
3. **三维度评分**：技术面（趋势）+ 资金面（流入）+ 预期面（催化剂）
4. **推荐清单输出**：给出具体个股 + 推荐理由 + 风险提示

### 第一步：获取市场资金流向数据

**使用 akshare 获取今日行业资金流向：**

```python
import akshare as ak
df = ak.stock_fund_flow_industry(symbol='即时')
```

**数据源：** 东方财富（实时数据，与同花顺一致）

**关键字段：**
- 行业名称、涨跌幅
- 资金净流入/流出（单位：亿元）
- 流入资金、流出资金
- 领涨股及涨幅

---

### 第二步：获取主力资金流向数据（关键！）

**⚠️ 重要：必须同时获取"资金净流入"和"主力净流入"两个维度**

**使用同花顺数据或东方财富数据获取主力资金流向：**
- 从用户提供的截图或数据中提取"主力净流入"
- 或者通过 WebSearch 搜索：`{板块名称} 主力资金流向 2026`

**关键判断逻辑：**
```
主力净流入 vs 资金净流入的差值 = 散户资金流向

示例：
- 电力板块：主力净流入 +24.62亿，资金净流入 +22.99亿
- 散户资金流向 = 22.99 - 24.62 = -1.63亿（散户净流出）
- **判断：主力在吸筹，散户在交出筹码，强烈看涨信号！**
```

## 重要原则

1. **用户主导选择**：先展示资金流向，让用户选择感兴趣的板块，不强推
2. **数据驱动**：所有推荐必须基于 akshare 实时数据 + a-share-data 技术指标 + WebSearch 搜索结果
3. **客观中立**：不夸大机会，不隐瞒风险
4. **风险优先**：明确标注每只股票的关键风险点
5. **三维度必查**：技术面、资金面、预期面缺一不可
6. **资金流向优先**：优先关注资金净流入且涨幅为正的板块（资金推动上涨）

## 注意事项

- **数据源准确性**：使用 akshare 的 `stock_fund_flow_industry(symbol='即时')` 获取行业资金流，数据与同花顺一致
- 龙头地位通过 WebSearch 搜索市值排名、行业地位判断，或使用 a-share-data 获取板块成分股
- 预期面挖掘是核心竞争力，必须深度搜索
- 评分标准可根据市场环境动态调整（牛市侧重技术面，熊市侧重预期面）
- 推荐个股数量：每个板块2只（优选+次选），其他候选股用户可用 /stock-check 进一步分析
- **资金流向解读**：
  - 涨幅为正 + 资金流入 → 强势板块，资金推动上涨
  - 涨幅为负 + 资金流入 → 资金抄底，可能反转
  - 涨幅为正 + 资金流出 → 拉高出货，警惕风险
  - 涨幅为负 + 资金流出 → 弱势板块，继续下跌
- **不要一次性分析所有板块**，先让用户选择

### 🔬 主力资金边际改善分析（2026-05-28 两轮验证，必读！）

**核心发现：主力资金边际改善是唯一可靠的短期预测因子（80%准确率），改善>50亿=100%。**

#### ⚠️ 先排除马后炮指标

领涨股涨停、今日资金净额这些是**同步指标**，跟涨跌同一天发生，不能用来预测明天。只使用昨日收盘已知数据。

#### 四象限分类（基于昨日主力数据）

```
D1主力净流入
    ↑
🔥流入且改善(1/2=50%)  │  📈流出但改善(3/3=100%) ← 最强！
                        │
────────────────────────┼────────────────→ 边际改善
                        │
⚠️流入但恶化            │  ❌流出且恶化(1/3上涨)
```

**核心规律：预测涨跌的不是"谁钱多"，而是"谁态度变了"。**

#### 纯预测因子准确率（5/27→5/28 验证）

| 预测因子 | 命中 | 准确率 | 结论 |
|----------|------|--------|------|
| 改善幅度>50亿 | 3/3 | **100%** | 大钱转向最可靠 |
| 主力边际改善>0 | 4/5 | **80%** | 唯一可用预测因子 |
| "流出但改善"象限 | 3/3 | **100%** | 超跌反弹最猛 |
| 主力边际恶化 | 2/3下跌 | 67% | 回避信号 |
| D1主力净流入>0 | 1/2 | 50% | 单独用不可靠 |

**剩下20%（小金属V反：-1→-32→+43→涨2.78%）是消息面和情绪面的事，资金数据预测不了。**

#### 判断铁律

1. **边际改善必须连续**：每天比前一天好，单日V反不算
2. **幅度越大越可靠**：>50亿=100%，<20亿需配合3日趋势
3. **趋势背景定生死**：3日涨幅>0恶化也能扛，3日涨幅<-3%改善也难翻
4. **四象限优先看"流出但改善"**：这个象限100%命中

#### 趋势优先级

| 优先级 | 趋势模式 | 信号强度 | 操作 |
|--------|---------|---------|------|
| 🔥🔥🔥 | 主力流出→流出收窄→逆转流入 | 最强 | 重点搞 |
| 🔥🔥 | 流出→流出大幅收窄(>50亿) | 强看涨 | 可以搞 |
| 🔥 | 持续流入且递增 | 顺势持有 | 看看 |
| ⚠️ | 流入但逐日递减 | 动能衰减 | 谨慎 |
| ❌ | 流出且逐日加速 | 回避 | 不搞 |
| ❌ | V型反转/单日逆转 | 不可靠 | 不纳入 |

**实战验证（5/27→5/28）：**
- 通信设备：-113亿→-26亿(+87)→+101亿 → +3.08% ✅
- 半导体：-253亿→-177亿(+76)→-44亿 → +2.27% ✅
- 消费电子：-78亿→-7亿(+71)→+31亿 → +2.05% ✅

- 化学制药：-14亿→+4亿(+18)→-19亿 → -0.73% ❌（改善<20亿+3日趋势-4.5%深跌）
